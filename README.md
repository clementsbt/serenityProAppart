# Serenity Pro Appart

Site vitrine pour une conciergerie Airbnb à Valfréjus — gestion locative, ménage, remise des clés, location de kits de draps et serviettes.

## Stack

- **Framework** : Next.js 14 (App Router)
- **Langage** : TypeScript
- **Hébergement** : Vercel

## Installation

```bash
npm install
npm run dev
```

Ouvrir http://localhost:3000

## Déploiement

Push sur `main` → déploiement automatique sur Vercel.

## Structure

```
src/app/
├── page.tsx           # Page d'accueil
├── layout.tsx         # Layout principal (meta, fonts, header, footer)
├── mentions-legales/  # Pages légales
├── services/          # Page services
└── globals.css        # Styles globaux
```
